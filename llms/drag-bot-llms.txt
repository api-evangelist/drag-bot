# drag&bot

> drag&bot is a web-based industrial robotics software platform for the intuitive setup, programming, and operation of industrial robots without prior robotics or coding skills. Built on ROS (Robot Operating System) and vendor-neutral across major robot brands, it lets production workers assemble robot programs by dragging and dropping reusable Function Blocks. Founded in Stuttgart in 2016, acquired by KEBA in 2021, and integrated into KEBA's Kemro X automation platform.

## Overview

- Product: no-code / low-code robot programming via drag-and-drop Function Blocks
- Foundation: ROS (Robot Operating System) — programmatic surface is ROS services, topics, and messages, not a public REST/HTTP API
- Robot support: KUKA, ABB, Universal Robots, FANUC, Denso, Kinova, Aubo, Robotis, plus grippers and peripherals
- Field integration: Modbus TCP/IP and MQTT modules; Siemens S7-1200 support
- Extensibility: Python/JSON Function Blocks and ROS-based Components (hardware drivers)
- Ownership: part of KEBA (Kemro X)

## Notes

- No public REST/HTTP API, OpenAPI, AsyncAPI, OAuth server, or /.well-known discovery surface is published (probed 2026-07-18).
- Integration is code-level via ROS (Python Function Blocks, ROS Components) rather than a hosted web API.
